Sobre Nós

Sobre a nossa equipe:

Somos uma equipe formada por quatro integrantes — Júlia Prdimm, Pietro Pansani, Dafny Calvanese e João Dantas — unidos pelo objetivo de desenvolver soluções tecnológicas inovadoras. Nosso projeto envolve modelagem de banco de dados, desenvolvimento Back-end e Front-end, criação de APIs e design de interfaces. Trabalhamos em conjunto para criar um sistema funcional, intuitivo e eficiente, unindo criatividade, tecnologia e colaboração para alcançar os melhores resultados.

Júlia Pardim - Front-end:

Responsável pelo desenvolvimento da interface do site, utilizando HTML e CSS para criar páginas organizadas, funcionais e visualmente agradáveis.

Pietro Pansani - Back-end:

Responsável pela lógica do sistema e pelo desenvolvimento das funcionalidades que garantem seu funcionamento.

Dafny Calvanese - Banco de Dados:

Responsável pela modelagem, organização e estruturação do banco de dados, garantindo o armazenamento adequado das informações.

João Dantas - Figma e Back-end:

Responsável pela criação dos protótipos e das interfaces no Figma, além de contribuir para o desenvolvimento do Back-end do sistema.
